Price-drop alerts

If you set a target price for a product, you are alerted only when it reaches that target.

Affiliate links (owner setting)

Off by default. When on, a Flipkart or Myntra product opened from a price-drop alert, or from the popup while it is a deal, goes through your affiliate network link. Links are never rewritten on page load, existing affiliate links are never replaced, and Amazon links never get an affiliate tag (the Amazon Associates rules do not allow it in browser extensions). Disclose this in the Chrome Web Store listing before turning it on. See docs/CHROME_WEB_STORE.md.

Use the deep-link format your affiliate network gives you. {url} is replaced with the encoded product URL. Must start with https://.

Your data

Price history is stored only in this browser. Nothing is sent to any server.
